# moth

Building controllable AI agents and production-minded backend systems.

I focus on runtime architecture, isolation, trust boundaries, observability, and evidence-driven evaluation. I work mainly with TypeScript, Java, and Python.

## Selected work

- **[coil-core](https://github.com/mothieras/coil-core)** — embeddable coding-agent engine with MCP, concurrent subagents, event-sourced sessions, and an observable runtime.
- **[EnterpriseKB](https://github.com/mothieras/enterprise-kb-rag)** — Java enterprise RAG with access control, citations, tool-calling agents, Docker deployment, and offline evaluation.
- **[MOJ Code Sandbox](https://github.com/mothieras/moj-code-sandbox)** — Docker-isolated Java/Python/C++ execution with reusable container pools and explicit resource limits.
- **[Agentic-RAG](https://github.com/mothieras/agentic-rag-for-dummies)** — an attributed LangGraph derivative focused on Chinese corpus governance, DeepSeek integration, evaluation, and FastAPI/SSE serving.
